拍板結論

建議重作，不修舊 App。

保留既有 SharePoint List 與欄位設計，重建乾淨的 Canvas App。第一階段只做模組一：今日出勤列表、Popup 回覆、Patch 寫回 `表單回覆`。

主方案與備案

方案 做法 適用情境
主方案 Screen 根層級建立 `OverlayContainer`，內放 `PopupCard`，用容器置中。 Power Apps 容器置中屬性可正常運作時。
備案 Screen 根層級建立 `rectPopupMask` + `ctnPopup`，用 `App.Width` / `App.Height` 計算置中。 `OverlayContainer` 置中仍跑掉時。

製作流程

  1. 檢查 SharePoint List `AttendanceHistory` 欄位是否存在。
  2. 新建 Blank Canvas App，先只做模組一。
  3. Settings > Display：關閉 `Scale to fit`、`Lock aspect ratio`、`Lock orientation`。
  4. Data > Add data > SharePoint，連接 `AttendanceHistory`。
  5. 設定 App `OnStart` 變數。
  6. 建立 `Screen2` 根層級結構：`ScreenContainer1` 與 `OverlayContainer` 同層。
  7. 建立今日出勤 `Gallery1`。
  8. 建立 Popup：方案名稱、任務名稱、回覆下拉、其他說明、關閉、儲存。
  9. 儲存時 `Patch` 回 SharePoint List。
  10. Save、Publish，使用一般員工帳號測試。

關鍵設定

App OnStart

Set(varMonth, Today());
Set(varShowPopup, false);
Set(varSelectedRecord, Blank());
Set(varUserEmail, User().Email);
Set(varReplyOptions, ["已處理", "待確認", "其他"]);

Gallery1 Items

Filter(
    AttendanceHistory,
    Email = varUserEmail &&
    DateString = Text(Today(), "yyyy/m/d")
)

Gallery1 OnSelect

If(
    !IsBlank(ThisItem.方案名稱),
    Set(varSelectedRecord, ThisItem);
    Reset(DropdownReply);
    Reset(TextInputOther);
    Set(varShowPopup, true)
)

OverlayContainer

Width = Parent.Width
Height = Parent.Height
X = 0
Y = 0
Fill = RGBA(0, 0, 0, 0.4)
Visible = varShowPopup
LayoutAlignItems = LayoutAlignItems.Center
LayoutJustifyContent = LayoutJustifyContent.Center

ButtonSave OnSelect

Patch(
    AttendanceHistory,
    varSelectedRecord,
    {
        表單回覆: If(
            DropdownReply.Selected.Value = "其他",
            TextInputOther.Text,
            DropdownReply.Selected.Value
        )
    }
);
Set(varShowPopup, false)

風險清單

權限

員工需要 App 使用權限，也需要 SharePoint List 可更新 `表單回覆` 的權限。若只有讀取權限，`Patch` 會失敗。

DateString

必須是 `yyyy/m/d`，例如 `2026/6/8`。若填成 `2026/06/08`，Gallery 會撈不到。

欄位內部名稱

SharePoint 欄位若曾改名，Power Apps 公式可能需要內部名稱，不一定等於顯示名稱。

Dropdown 屬性

若 `DropdownReply.Selected.Value` 報錯，改查控制項實際欄位，可能要用 `.Result`。

驗收檢查

  • Data 面板看得到 `AttendanceHistory`。
  • Gallery 只顯示登入者今天資料。
  • 只有 `方案名稱` 不為空的列會開 Popup。
  • Popup 開啟時遮罩全畫面，Popup 置中。
  • 選「其他」時才顯示文字輸入框。
  • 儲存後 SharePoint List 的 `表單回覆` 確實更新。
  • 公式列沒有 delegation 黃色警告。
  • Publish 後用一般員工帳號測試成功。
