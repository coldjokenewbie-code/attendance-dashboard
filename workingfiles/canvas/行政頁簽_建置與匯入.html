行政查核頁簽 — 建置與匯入

2026-06-16 ｜ Claude@Mac ｜ 同一 app 內、權限控制的行政專用頁簽
設計：行政頁簽是 app 內第二個畫面 ScrAdmin。列當天所有員工直接從 AttendanceHistory 當日資料去重到「人」（09:40 已同步全體），不靠 team_member。team_member 只用來判權限：ScrToday 的「行政查核」按鈕 Visible 直接算 LookUp，只有行政登入才看得到、才進得了 ScrAdmin。

1. team_member 準備

  1. 在 team_member 工作表新增欄 出勤存取權限，行政人員那列填值（任何非空值即視為行政；空白＝一般員工）。
  2. App 左側「資料」→ 新增資料 → 連 Excel（TaskDB.xlsx）→ 勾 team_member Table。資料源名須為 team_member。

未驗證：判斷式目前用「出勤存取權限 非空白＝行政」。若你要用「是／否」或特定文字，告訴我，我把 !IsBlank(...) 改成 =... ="是" 之類。

2. 建 ScrAdmin 畫面

  1. Studio 左側「+ 新畫面」→ 空白 → 命名 ScrAdmin。
  2. 選取畫面，設 Screen.Fill = RGBA(243,244,246,1)。
  3. 開 ScrAdmin_paste.pa.yaml 全選複製 → 畫布 Cmd/Ctrl+V。

3. 更新 ScrToday（加行政入口）

ScrToday_paste.pa.yaml 已更新（Header 加高、加 btnAdmin）。最省事：刪掉 ScrToday 既有控件、重貼整份新 YAML。btnAdmin 的 Visible 已內建權限判斷、OnSelect 為 Navigate(ScrAdmin)。

4. 行政頁簽功能

  • 逐人一張卡（姓名／員工編號／Email／目前狀態／任務筆數）。
  • 下拉選出勤狀態 → 按「儲存」→ 寫回該人當天所有任務列的 實際出勤狀態。
出勤狀態選項
  1. 0930已到
  2. 1000已到
  3. 10:00前已發**
  4. 1000未到，已提醒
  5. 1000未到，已發米米信
  6. 1000未到，請假
  7. 異地(其他縣市)
  8. 已發**先去場館後進公司
  9. 當日休假
  10. 臨時請假

5. 驗證

  1. 用行政帳號登入 → ScrToday 右上出現橘色「行政查核」鈕；一般員工帳號看不到。
  2. 點進 ScrAdmin → 看到今日全體去重清單。
  3. 選某人狀態 → 儲存 → 該人所有今日列的 實際出勤狀態 都更新。
  4. 回 ScrToday（← 我的回覆），一般員工頁籤運作不變。

6. 未驗證 / 提醒

  • UI 隱藏非安全邊界：Visible 只是畫面層，懂技術者仍可能繞過。員工不能改 實際出勤狀態 的硬保障要靠 SharePoint 清單欄位／項目權限。
  • GroupBy / UpdateIf 對 SharePoint 非完全委派；當日資料量小可運作，資料變大需留意上限警告。
  • team_member 走 Excel 連接器直讀（非委派，team_member 量小可接受）。
  • 狀態選項含 **／米米信 為照你原文，如需更名直接說。
