出勤查核儀表板 — 第一版建置指南

2026-06-21 ｜ Claude@Mac ｜ 一般同事頁 + 行政專用頁簽（權限控制）・響應式手機優先
上次 PA1001 的原因（已修正）：我把兩個畫面塞進同一個檔，你整段貼上 → 出錯。Power Apps「貼上程式碼」一次只能貼一個畫面的控件。本版改回「一個檔 = 一個畫面」，每個檔全選複製、整段貼上就好（和你之前成功的做法一樣）。合併檔已刪除。
兩個檔（在 workingfiles/canvas/）
檔案對應畫面內容
ScrToday_paste.pa.yamlScrToday一般同事：今日卡片、填回覆、右上角行政入口
ScrAdmin_paste.pa.yamlScrAdmin行政專用：當天全體去重、逐人填出勤狀態

前置（只做一次）

1
加資料源（App 左側「資料」→ 新增資料）：
  • AttendanceHistory —— SharePoint 清單。
  • team_member —— Excel 連接器（須含 Email 與 出勤存取權限 欄）。
名稱要與此完全一致，公式才接得到。
2
開響應式：Settings → Display → 關閉「縮放以符合螢幕 (Scale to fit)」。
（本版尺寸全用 Parent.Width / Parent.Height 比例、單欄直向，手機可讀。）

畫面 1：ScrToday（一般同事）先做這個

1
左側「+ 新畫面」→ 空白 → 命名 ScrToday。
2
選取畫面，設兩個屬性：
Fill=RGBA(243, 244, 246, 1)
OnVisible=UpdateContext({locShowPopup: false, locShowAll: false})
3
開 ScrToday_paste.pa.yaml → 全選複製（Cmd+A、Cmd+C）。
4
回 Studio，選到 ScrToday 畫面 → 樹狀檢視該畫面按 ⋯ → 貼上 → 貼上程式碼（或畫布 Cmd/Ctrl+V）。第一次貼會要你允許剪貼簿權限，按允許。

畫面 2：ScrAdmin（行政專用頁簽）

1
「+ 新畫面」→ 空白 → 命名 ScrAdmin。
2
選取畫面，設 Fill = RGBA(243, 244, 246, 1)。
3
開 ScrAdmin_paste.pa.yaml → 全選複製。
4
選到 ScrAdmin 畫面 → ⋯ → 貼上 → 貼上程式碼。

權限怎麼運作

ScrToday 右上角的橘色「行政查核」鈕，Visible 內建判斷：

=!IsBlank(LookUp(team_member, Email=User().Email, '出勤存取權限'))

只有 team_member 裡 出勤存取權限 非空白（你的資料是 行政管理）的帳號才看得到這顆鈕、才能進 ScrAdmin。一般員工看不到。（= 比對本就不分大小寫，故不需 Lower()，可免委派警告。）
注意：UI 隱藏只是畫面層、非安全邊界。員工不能改 實際出勤狀態 的硬保障，要靠 SharePoint 清單的欄位／項目權限設定，這顆 Visible 擋不住懂技術的人。

測試

  1. 一般員工帳號登入：看到自己今日卡片；右上沒有行政查核鈕；「填寫回覆」可選 4 選項送出。
  2. 行政帳號（陳怡惠 / 黃文郁）登入：右上出現橘色「行政查核」→ 點進 ScrAdmin → 當天全體逐人列出 → 選出勤狀態 → 儲存 → 回寫該人當天所有列。
  3. 切「全部紀錄 / 今日」確認歷史查得到。
