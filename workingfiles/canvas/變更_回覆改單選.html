改了什麼

  • Popup 的「多行文字輸入框」txtReply → 換成「單選清單」radReply。員工點一項即回覆，送出把整段文案寫入 表單回覆。
  • 整份改為響應式、手機優先：所有尺寸改用 Parent.Width / Parent.Height 比例，單欄直向；卡片與按鈕整寬、Popup 佔屏自適應。

響應式設定（YAML 貼不進、需手動）

  1. Settings → Display → 把「縮放以符合螢幕 (Scale to fit)」關閉，App 才會依實際手機寬伸縮。
  2. 畫面層級兩屬性手動設定：
    Screen.Fill = RGBA(243,244,246,1)
    Screen.OnVisible = UpdateContext({locShowPopup:false, locShowAll:false})

怎麼套用到 Studio

最省事：在 Studio 把整個畫面控件刪除，重貼一次更新後的 YAML。或只動 Popup：

  1. 刪掉 Popup 內的 txtReply 控件。
  2. 從更新後 YAML 複製 radReply 區塊，貼進同一層（conPopup 內）。
  3. 檢查送出按鈕公式已是 radReply.Selected.Value、填寫按鈕 OnSelect 已是 Reset(radReply)。

需實機確認（未驗證）

  • Classic 單選控件的版面屬性此處寫 Layout = Layout.Vertical（推測）。若貼入後報屬性名錯誤，改用 Studio 右側面板的「版面配置」改直向即可，不影響邏輯。
  • 四個選項文字較長，Popup 高度 480 / 單選區高度 220 應足夠；實機若有截斷再調高度。
